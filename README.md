# 🌴 Espaço Casa na Praia

> Modelo de site para apresentação e divulgação de um espaço para realização de festas e eventos.

O **Espaço Casa na Praia** é um projeto desenvolvido com o objetivo de criar uma presença digital moderna, elegante e convidativa para um salão de festas.

A proposta do site é apresentar o espaço de forma visualmente atrativa, destacando sua estrutura, ambientes e possibilidades para diferentes tipos de eventos, além de facilitar o contato de potenciais clientes.

## ✨ Sobre o Projeto

O projeto foi criado como um **modelo comercial (projeto demonstrativo)** para um espaço de eventos.

A ideia é proporcionar ao visitante uma experiência simples e agradável, permitindo que ele conheça o ambiente e tenha facilidade para entrar em contato e solicitar informações sobre reservas, valores e disponibilidade.

## 🎯 Objetivos

* Apresentar o Espaço Casa na Praia de forma profissional;
* Destacar os ambientes e a estrutura do local;
* Atrair novos clientes;
* Facilitar o contato para reservas e orçamentos;
* Criar uma identidade visual moderna e sofisticada;
* Demonstrar como um site profissional pode ajudar um negócio local.

## 🖥️ Funcionalidades

* 🏠 Página inicial com apresentação do espaço;
* 📸 Galeria de fotos;
* 🎉 Informações sobre eventos;
* 📍 Localização do espaço;
* 📱 Botão de contato pelo WhatsApp;
* 📋 Informações sobre serviços e estrutura;
* 📞 Área de contato;
* 📱 Design responsivo para celulares, tablets e computadores.

## 🛠️ Tecnologias Utilizadas

* **HTML5** — Estrutura do site
* **CSS3** — Estilização e responsividade
* **JavaScript** — Interações e funcionalidades
* **Git/GitHub** — Versionamento e gerenciamento do projeto

## 🎨 Proposta Visual

A identidade visual foi pensada para transmitir:

* 🌴 Conforto
* ✨ Elegância
* 🌊 Clima praiano
* 🎉 Celebração
* 🏡 Aconchego

O design busca fazer com que o visitante tenha uma primeira impressão positiva e consiga visualizar o espaço como cenário para seu próximo evento.

## 📱 Responsividade

O site foi desenvolvido pensando em diferentes tamanhos de tela, proporcionando uma experiência adequada em:

* 📱 Smartphones
* 💻 Computadores
* 📲 Tablets
